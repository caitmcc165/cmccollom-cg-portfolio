# Publish your *new* portfolio on GitHub Pages

The existing `cait-portfolio` repository stays untouched.

1. Go to **https://github.com/new** and create a **new public repository** named `coastal-garden-portfolio`. Use your GitHub account (`caitmcc165` if unchanged). Do not select the existing `cait-portfolio` repository.
2. Download and extract the website ZIP. In your new repository, choose **Add file → Upload files**. Upload the **contents** of the extracted folder: `index.html`, `work.html`, `about.html`, `contact.html`, the `css`, `js`, and `assets` folders, `.nojekyll`, and the Markdown guides. Do not place `index.html` inside an extra folder.
3. Commit the uploaded files to the new repository's `main` branch.
4. Go to **Settings → Pages → Build and deployment**. Under **Source**, select **Deploy from a branch**. Select `main`, folder `/ (root)`, then **Save**.
5. Once GitHub Pages reports the website is published, open the URL shown in Pages settings. With the suggested repository name, it should be at `https://caitmcc165.github.io/coastal-garden-portfolio/` if the username remains unchanged. This URL does **not exist until you publish**.
6. Confirm the home page, Work, About, Contact, download link, mobile menu, Pause petals control, implementation steps, and checklist.

If you prefer assistance uploading it with the connected GitHub app, create the **empty new repository** first and return with the repository link. No edits to your current portfolio are required.
